# กินรัยดี (Kinraidi) 🎲🍽️

เว็บช่วยแก๊งเพื่อนตัดสินใจ "มื้อนี้กินอะไรดี" โดยจับคู่ **MBTI + สิ่งที่ชอบ** ของทุกคนในตี้ เข้ากับ **บรรยากาศร้าน** แล้วสุ่มร้านที่ทุกคนแฮปปี้ที่สุด
โปรเจกต์วิชา — คณะ ICT ม.ศิลปากร

🌐 **เว็บจริง:** https://kinraidi.vercel.app · 💻 **โค้ด:** https://github.com/Suphanut07/kinraidi
บัญชีเดโมสำหรับพรีเซนต์: `poy@demo.com` / `123456` (มีเพื่อน 7 คน + กลุ่ม 3 กลุ่ม) · เพื่อนคนอื่น: `money@ tan@ kao@ regency@ gam@ tako@ prib@` + `demo.com` รหัสเดียวกัน

## อัปเดตเว็บจริง
แก้โค้ด → VS Code แท็บ Source Control → พิมพ์ข้อความ → **Commit** → **Sync Changes (Push)** → Vercel อัปเดตเว็บให้เองใน ~1 นาที

## เพิ่มรูปร้าน
สร้างโฟลเดอร์ `รูปร้าน/<ชื่อร้าน>/` แล้ววางรูปอะไรก็ได้ (ไม่ต้องตั้งชื่อ) จากนั้นบอก Claude Code ว่า "ย้ายรูปร้านให้หน่อย"
Claude จะแปลง/ย่อ/ตั้งชื่อ แล้ววางใน `assets/img/` ให้ (โฟลเดอร์ `รูปร้าน/` ไม่ถูกอัปขึ้น GitHub)

## วิธีรันในเครื่อง (VS Code + Live Server)
1. เปิดโฟลเดอร์นี้ใน VS Code
2. คลิกขวาที่ `index.html` → **Open with Live Server**
3. ถ้ายังไม่ใส่ค่า Supabase เว็บจะอยู่ใน **โหมดเดโม** (มีแถบเหลือบนสุด) ล็อกอินด้วย `poy@demo.com` / `123456`

> ทำงานร่วมกันผ่าน **Live Share** ได้เลย ไม่ต้อง build อะไร เพราะเป็น HTML/CSS/JS ล้วน

## โครงสร้างไฟล์
```
index.html          หน้าหลัก (สุ่ม / มื้อนี้ไปกับใคร / เงื่อนไข / ร้านแนะนำ)
result.html         ผลสุ่ม "นี่คือร้านอาหารของคุณ !!" + % แมตช์ + เหตุผล
restaurant.html     รายละเอียดร้าน (กด "อ่านต่อ")
member.html         กลุ่มของฉัน + รายชื่อเพื่อน + QR
history.html        ร้านโปรด + ร้านที่ดูล่าสุด
history-list.html   ดูทั้งหมด (?type=fav | recent)
profile.html        โปรไฟล์ / สิ่งที่ฉันชอบ / MBTI / ตั้งค่า
login.html, signup.html
join.html           ปลายทางเมื่อสแกน QR (เข้าร่วมมื้อ / เพิ่มเพื่อน)

css/style.css       สี ฟอนต์ ปุ่ม การ์ด popup (ตาม Style guide)
css/pages.css       สไตล์เฉพาะแต่ละหน้า
js/config.js        ⭐ ใส่ Supabase URL + key ตรงนี้
js/data/restaurants.js  ⭐ ข้อมูลร้าน 20 ร้าน (ทีมแก้ไขได้)
js/match.js         ระบบจับคู่ร้าน (อธิบายวิธีคิดคะแนนไว้ในไฟล์)
js/api.js           เชื่อมฐานข้อมูล (โหมดเดโม / Supabase)
js/ui.js            header, footer, popup, ไอคอน, การ์ดร้าน
js/detail.js        ส่วนแสดงรายละเอียดร้าน
js/pages/*.js       โค้ดของแต่ละหน้า
supabase/schema.sql ตาราง + สิทธิ์ (RLS) + ที่เก็บรูป
assets/             โลโก้ / รูปร้าน / รูปตกแต่ง
```

## รูปภาพที่ทีมต้องใส่ (Export จาก Figma)
| ไฟล์ | ใช้ที่ |
|---|---|
| `assets/logo.png` | โลโก้ header/footer/หน้า login (สี่เหลี่ยมจัตุรัส) |
| `assets/hero/food1.png` … `food10.png` | จานอาหารลอยๆ ในหน้าแรก (วงกลม พื้นใส) |
| `assets/hero/profile-side.jpg` | รูปข้างการตั้งค่าในหน้าโปรไฟล์ |
| `assets/img/<id>-1.jpg` | รูปหลักของร้าน (id ดูใน restaurants.js เช่น `sainom-1.jpg`) |
| `assets/img/<id>-2.jpg` | บรรยากาศภายในร้าน |
| `assets/img/<id>-3.jpg` | เมนูอาหาร & เครื่องดื่ม |

ลำดับที่เว็บหารูป: ① ไฟล์ในโฟลเดอร์ `assets/` → ② รูปบน Supabase Storage (bucket `restaurants`, ดึงจาก Figma ไว้แล้ว 23 รูป) → ③ พื้นสี + อีโมจิ
ดังนั้นอยากเปลี่ยนรูปไหน แค่วางไฟล์ชื่อเดียวกันใน `assets/` ได้เลย

รูปที่มีบน Supabase แล้ว: โลโก้, รูปอาหารหน้าแรก 7 รูป, รูปข้างหน้าโปรไฟล์, และรูปร้าน
ใส่นม (1-3), BRUNCH OVER BREAKFAST (1-3), TAMA (1-3), ครัวโทเก้, Yoi Soup, BAKE TILL WE DIE, ยำว่ะ, ครัวคุณเมี่ยง (รูปหลัก)

> เว็บนี้ทำเพื่อการศึกษา — มีข้อความแจ้งที่ footer และเครดิตภาพใต้หน้ารายละเอียดร้าน
> ใส่ที่มาของภาพเฉพาะร้านได้ในช่อง `photoCredit` ของแต่ละร้านใน `restaurants.js`

## ข้อมูลร้าน
อยู่ใน `js/data/restaurants.js` — **ฉบับร่าง ต้องเช็กหน้าร้านจริง** (เวลาเปิด-ปิด, พิกัด, ราคา, ฟีเจอร์ แอร์/สัตว์เลี้ยง/ที่จอดรถ)
พิกัด: เปิด Google Maps → คลิกขวาที่ร้าน → คลิกเลขพิกัดเพื่อคัดลอก → ใส่ `lat`, `lng`

## Supabase (ตั้งค่าเสร็จแล้ว ✅)
- โปรเจกต์ `kinraidi` (Singapore) — URL + key อยู่ใน `js/config.js` (ลบ 2 ค่านี้ = กลับไปโหมดเดโม)
- ตาราง + สิทธิ์ (RLS) ตาม `supabase/schema.sql` · Confirm email ปิดแล้ว · บัญชีเดโมสร้างแล้วด้วย `tools/seed.html`
- Storage: `images` (รูปโปรไฟล์/กลุ่มที่ผู้ใช้อัปโหลด), `restaurants` (รูปจาก Figma)

## QR ข้ามเครื่อง
QR ชี้ไปที่ URL ที่เปิดเว็บอยู่ → ใช้จากมือถือได้เมื่อเปิดผ่าน https://kinraidi.vercel.app (ถ้าเปิดผ่าน `127.0.0.1` มือถือเข้าไม่ได้)
